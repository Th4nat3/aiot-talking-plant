🌿 AIoT Eco-Companion: Talking Plant

เว็บไซต์สื่อการเรียนรู้เทคโนโลยี AIoT การเชื่อมต่อ ESP32, MQTT Broker, Groq AI (LLaMA 3.3) และ Telegram Bot

แนวคิดของโปรเจกต์ (Concept)

โปรเจกต์ "AIoT Eco-Companion: Talking Plant" เป็นการพัฒนาระบบดูแลต้นไม้อัจฉริยะที่เปลี่ยนข้อมูลจากเซ็นเซอร์กายภาพให้กลายเป็น "บทพูดที่มีอารมณ์ความรู้สึก" ผ่านระบบ Generative AI โดยต้นไม้จะสามารถบอกเล่าสภาพอากาศ ความชื้นในดิน และความต้องการของตนเองผ่านแอปพลิเคชัน Telegram ได้อย่างน่ารักและเป็นธรรมชาติ

วัตถุประสงค์การเรียนรู้ (Learning Objectives)

  • เรียนรู้การอ่านค่าเซ็นเซอร์กายภาพ (I2C และ ADC) ด้วยบอร์ด ESP32-S2 (Cucumber RS)
  • ศึกษาการสื่อสารข้อมูล IoT ด้วยโปรโตคอล MQTT ผ่าน Public Broker
  • ประมวลผลข้อมูล IoT ร่วมกับ Large Language Model (Groq API - LLaMA 3.3)
  • สร้างระบบแจ้งเตือนอัตโนมัติไปยังอุปกรณ์ผู้ใช้ผ่าน Telegram Bot API

แผนผังการทำงานของระบบ (Data Flow Architecture)

ระบบแบ่งการทำงานออกเป็น 4 ส่วนหลัก ตั้งแต่การตรวจวัดจากอุปกรณ์ไปจนถึงการประมวลผลด้วย AI ดังนี้:

1. Edge Sensing

บอร์ด ESP32 อ่านค่าอุณหภูมิ/ความชื้น (HTS221) และความชื้นดิน

2. MQTT Transport

ส่งข้อมูลโครงสร้าง JSON ผ่าน Publish Topic /plant/status

3. Cloud AI Processing

Google Colab ดึงข้อมูล MQTT และให้ Groq AI (LLaMA 3.3) แต่งคำพูด

4. User Interface

ส่งข้อความแจ้งเตือนอารมณ์ของต้นไม้เข้าแอป Telegram ในมือถือ

การต่อพินฮาร์ดแวร์ (Cucumber RS Pinout Mapping)

ตารางแสดงการเชื่อมต่อขาสัญญาณของบอร์ด Cucumber RS (ESP32-S2) ร่วมกับเซ็นเซอร์:

อุปกรณ์ / เซ็นเซอร์ ประเภทสัญญาณ ขาบนบอร์ด ESP32 หมายเหตุ
HTS221 (SDA) I2C Data GPIO 41 สายส่งข้อมูล I2C onboard
HTS221 (SCL) I2C Clock GPIO 40 สายนาฬิกา I2C onboard
Soil Moisture Sensor Analog Output GPIO 1 กลุ่มขา ADC1 (อ่านค่าอนาล็อก 0-4095)

  Serial.begin(115200);
  Wire.begin(41, 40); // กำหนดขา I2C Cucumber RS (SDA=41, SCL=40)

  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) { delay(500); }
  client.setServer(mqtt_server, 1883);
}

บทเรียนที่ 1: ความรู้พื้นฐาน AIoT

AIoT (Artificial Intelligence of Things) คือการนำเทคโนโลยีปัญญาประดิษฐ์ (AI) เข้ามาเสริมประสิทธิภาพให้กับระบบ IoT ช่วยเปลี่ยนข้อมูลดิบ (Raw Data) จากเซ็นเซอร์ ให้กลายเป็นข้อมูลเชิงวิเคราะห์ที่มีคุณค่าและตอบสนองกับมนุษย์ได้สมจริงยิ่งขึ้น

บทเรียนที่ 2: โปรโตคอล MQTT ในงาน IoT

MQTT เป็นโปรโตคอลสื่อสารน้ำหนักเบาที่ทำงานแบบ Publish/Subscribe เหมาะอย่างยิ่งสำหรับอุปกรณ์ข้อจำกัดสูง เช่น ESP32 โดยข้อดีคือประหยัดพลังงาน รับส่งข้อมูลรวดเร็ว และยืดหยุ่นสูง
